My perspective of using AI in programming has not really changed. Coming in to the semester I already understood the benefits of AI to help working through solutions to problems and to quickly generate code. I was also aware of the traps of not reviewing the generated code and allowing the agent to basically do all the work.  This class reinforced the healthy balance that programmers should aim to have with AI, using it to gain deeper understanding of concepts, algorithms etc. while using it like a partner to build reliable solutions that are thoroughly tested and verified to ensure proper functionality.
Going forward I aim to be more mindful of how I use AI to ensure I don't fall into total dependence, but use it as an enhancer to boost productivity and efficiency in my work.
