Template method is used to define the overall flow or structure of a class but allows subclasses to fill in the details of exactly how it want the functions to be done. In this example Report outlines a template that has LoadData, formatHeader, formatBody, formatFooter and generateReport. It does not specify exactly what happens in these function and thus the student and course format the info necessary to them. Example, in the student report the formatBody() prints student name and gpa but it prints course and enrollment for the course report.
